# R33 動漫戰鬥重製

使用者回饋：R32 的畫面仍醜，玩起來沒有爽感。選定方向：華麗動漫風，大招與爆裝演出。版本：0.21.0-r33。本次仍為本機修改／匯出，未 push 或部署到線上。

## 實際重做

- 角色與魔物換成原創 cel／墨線造型，17 種角色各 27 格 idle、walk、attack、hurt、death 真姿勢。隊長放大，加入胸甲、金邊與護膝細節；保留 physics root 與第 2 格命中，沒有以整張角色旋轉冒充走路或攻擊。
- 三套魔法遺跡使用世界座標石材、封印、祭壇與寶石；移除原本亮折線、巨大晶石框和大片黑底。根據實玩再減淡縫線、裂紋與刻紋。
- 主選單與載入畫面改為內建 imagegen 製作的原創四人動漫插畫。戰鬥使用可重建的逐格 sprites，不把封面當成戰鬥品質證據。
- 隊長近身每 0.72 秒自動斬；移動 1.15 秒蓄勢，空白鍵／手機「斬」發動 270 範圍、138° 金白刀光。滿蓄傷害 108，冷卻 2.35 秒；收招中的輸入緩衝 0.65 秒。敵人砍飛、死亡與經驗回收連成一段。
- 飛刀、飛彈、榴彈與迴旋刃換為清楚的小型動漫形狀；移除反覆浮在人物頭上的巨大 COMBO 字與大量煙圈。手機刀光採地板透視，避免主要刀刃跑出畫面，傷害範圍不變。
- 戰鬥頂欄由手機約 118 px 縮為 58 px。裝備提示改底部短幅，詳細收益留在裝備槽。冷卻數字不再與「斬」字重疊。
- 「開始出擊」直接進場；情境教學從暫停重看，種子出擊保留契約。第一級 XP 門檻 24，選卡直接開啟、無額外慢動作；手機單次點選，桌機可按 1／2／3。
- 遊戲 PCK 改為內容指紋檔名，避免瀏覽器拿到 R32 舊包。新版名稱及 SHA-256 見 [匯出紀錄](evidence/r33/pwa_cache_verification.json)。

## 實玩與修正

獨立代理透過真實瀏覽器鍵鼠／原生 touch events 操作，未注入 HP、敵人、等級或裝備。第二輪桌機與手機都自然完成約 91 秒，分別 420 殺／410 殺、Lv.8、6 次單擊升級、19 件裝備拾取。清群最大單斬分別 4 隻／7 隻。

第一輪發現第二次升級卡片落到看不見的第二列，已修正：先移出舊 Grid children 再回收，入場動畫只改 alpha／scale，不修改容器管理的位置。兩設備第二輪真滑鼠／觸控連續選卡通過；另有四次連續換卡的引擎回歸。

收尾把招募卡改為新 atlas 的 idle 圖示、補角色護甲細節。短局補驗與完整限制見 [體驗員報告](playtest/R33_PLAYTEST.md)。影像、碰撞、數值與回歸通過不能代替使用者的美感／樂趣判定；本報告不宣稱使用者已接受新版。

## 可重建與檢查

- 角色：`scripts/services/r33_sprite_painter.gd`、`scenes/debug/R33SpriteBake.tscn`。
- 場景：[R33_ART.md](R33_ART.md)，包含 native OpenGL 三主題的實際渲染與移動／快取檢查。
- 戰鬥：[R33_COMBAT.md](R33_COMBAT.md)，包含第 2 格命中、輸入緩衝、蓄勢、手機刀光與效果上限。
- UI：`R33ExperienceRegressionTest` 驗證兩畫幅連續四次卡片仍可見、58 px 頂欄。
- 核心回歸與原始輸出：`docs/evidence/r33/final-gates/`；檢查 exit code 與腳本錯誤，沒有只看 PASS 文字。

## 保留的限制

人物仍是簡化的程式繪製造型，細緻程度低於選單插畫；地面仍有規整重複感，可繼續美術加工。手機是瀏覽器模擬，未做實體觸控／熱機長跑；音訊未由體驗員實際聽聞。自然局未完成 Boss 與無盡終局，相關事件以引擎 gate 補驗，沒有冒稱玩過。
