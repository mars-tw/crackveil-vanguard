# R36 優化計畫：霜牆像冰牆、清遮擋、戰後首頁減字

版本 **0.65.0-content-r36**，基準 `40ef893`（R35）。

## 來源
- R35 Claude 8.8、Codex 8.9（陣形決策 9.8），皆嚴重 0。兩份：霜牆像介面條、不像場景裡的冰牆（Claude 第 1 項、Codex 第 5 項）；霜牆結論與失敗字未入鏡（Claude 第 2 項）；戰鬥畫面遮擋與資訊層級（兩份）；戰後頁金色小字過密（Codex 第 3 項）。Claude 放大確認：「擊破・極霜守望者」被右側戰報蓋住、點名框蓋住「散快」陣形卡、攻防框框線穿過第二行字、整備副標「三」字貼角落圖示。

## 清單
1. 霜牆改為場景中的冰牆：推進方向前方三層冰霧、陰影＋正面＋亮面三層牆體、冰磚縫線、朝推進方向的冰刺；缺口兩側發光綠柱與連線、向內箭頭加深色描邊。驗收：單元；審查圖第五關。
2. 霜牆結論「全員穿過霜牆／霜牆凍住 N 人」顯示 2 秒，並由審查機器人在結論出現時截圖（HUD 探針公開時間，只讀）。驗收：審查圖。
3. 「擊破・名稱」等大字遇右側欄（小地圖、關卡標、戰報）時橫移出 132 px 範圍，不再被蓋。驗收：單元。
4. 封隙點名若會壓到陣形答案卡或其他字牌，改放橫幅上方。驗收：單元。
5. 攻防框：上邊距維持 10（R10 框角規則），下邊距 9→3、行距 2→0、說明字 11→10，第二行不再被框線穿過。驗收：單元。
6. 整備副標起點 12→24，離開角落圖示。驗收：單元。
7. 戰後首頁減字：「隊員追擊」與各關危險統計移到「紀錄」分頁的「戰況統計」卡；金色行加 4 px 行距，字級不再被迫縮小。驗收：單元；審查圖勝利結算。
8. 固定閘門。

## 不在本輪
- 第六關新機制（下一輪單獨做）。
- 手機戰鬥頂欄兩行合併、整備頁三段式重排。
