# Crackveil Vanguard 內容優化 R48 計畫

基準 `c7677a1`（商店 build 7，內容 0.76.0-content-r47）。使用者指示：Crackveil 送新版給 Apple 之後「繼續優化遊戲內容」。依 `game-optimization-round` 八大面向，本輪重點放在 R47 留下的缺口：時輪齒核還沒目視確認、真人難度未知、遠征任務沒有第十關、齒核與基座仍是向量畫。Codex 到 2026-11-19 上午才能再派工，A、B 兩線由 Claude 子代理施工，MUSE 出圖。本機 GPU 依全域規則優先給 H3 產片，瀏覽器截圖一律用軟體繪圖（`--disable-gpu`／SwiftShader）。

## A 線（Claude 子代理）：第十關玩法加深與遠征任務
1. 遠座難度：機器人 6／6 成功、零過載，真人可能太容易。改成遠座離掉落點更遠一點，或搬運時間從 9 秒縮短（擇一，寫清理由），並讓「搬運中被打中」有看得見的代價（例如齒核掉落、要重新撿）；用自然機器人局驗證遠座成功率落在合理範圍（不是 100%，也不是 0%）。
2. 遠征任務加第十關：時輪工坊兩個任務——field：單次出擊把齒核送進遠座 N 次；mastery：送進遠座至少 M 次並完成工坊通關。獎勵與其他關一致；同步 R46 遠征測試裡固定的任務總數與獎勵合計（屬規則改變，照實寫原因）。
3. 結算畫面：工坊局的結算要寫出「送進近座／遠座各幾次、過載打中幾次、Boss 彈幕延後幾次」，以及一句可照做的改法。
4. 測試：新增 R48 單元與整合測試（沿用 R47 的測試方式），既有測試不得放寬。
