# R34 優化計畫：雷柱名牌置頂、分流成敗明示、被電有後果、戰績與關鍵貢獻修正

版本 **0.63.0-content-r34**，基準 `8efb7c0`（R33）。

## 來源
- R33 Claude 8.7（嚴重 0）、Codex 8.8（**嚴重 1**：19、20 雷柱規則字被隊長皇冠、陣形圖示與角色遮住）。兩份：分流成功看不到；「雷柱分流 0/7」不該算戰績。Codex：成功／失敗要有明確瞬間，失敗說出缺隊長或缺隊員。Claude：被電要痛、看得懂；「回復減傷 8」像算錯；上方雷柱被頂欄蓋住。

## 清單
1. 雷柱名牌改畫在最上層標記層（z 120），不再被光圈、皇冠、陣形圖蓋住。驗收：單元；審查圖第四關。
2. 雷柱落點方向：從 8 個方向挑兩柱離畫面邊緣與頂欄（150）最遠的那個（任何方向都可解，隊長走上一柱隊伍就會轉向）。驗收：單元；審查圖兩柱都在畫面內。
3. 分流成敗瞬間：成功「分流成功・無人受傷」（綠框）；失敗「分流失敗・隊長沒有踩柱」或「分流失敗・另一柱沒有隊員」（黃框），畫在所有「電」標記之上。驗收：單元；審查圖。
4. 被電有後果：傷害 16→20，另減速 1 秒。驗收：單元。
5. 戰績只列打贏過的危險：躲過熔火環、雷柱分流 0 次成功時不列。驗收：單元。
6. 關鍵貢獻：先選回復減傷（治療者少），再選封隙、承傷；回復減傷與承傷至少 30、封隙至少 3 秒，零頭不列。驗收：單元。
7. 審查機器人在分流成功瞬間截圖（HUD 探針公開最近一次分流時間，只讀）。
8. 舊測試依核准規則同步：R33（雷柱軸向、關鍵貢獻排序）。
9. 固定閘門。
