- 進度、領獎旗標與錢包沿用同一存檔交易；失敗回復，不顯示已領取，任務頁可重試。
- 舊存檔、升級、徽記與未知欄位保留；不把歷史紀錄當本輪任務補發。
- 藤蔓新增完整作用期間結束、隊長仍存活且零命中的事件；生成、暫停、提前移除與跨局殘留不計成功避招。
- 種子練習後從地圖正常出擊會清除舊種子；避免正常場次一直被排除。
- 任務文字所需中文字型已重建，來源字元覆蓋 1074／1074，字型 1,538,176 bytes，仍在既有大小上限內。
