# Crackveil Vanguard R50 無盡遠征練習紀錄

本機開發版為 `0.79.0-content-r50`。一場無盡遠征結束後，重回世界地圖選擇同一關，關卡說明的第一段會告訴玩家上次哪招值得再練。

- 上一場遇到三次影槍、只護住一次，地圖會顯示「1/3 次影槍鎖定」，並提醒隊長走到被鎖定的隊員身邊。
- 如果出過的招都處理成功，會顯示整場成功次數、其中一種實際處理過的招式，以及可以繼續使用的做法。若菁英來不及出招，只會記下這場還沒出招。
- 每關各自保留最近一場。歷史最高波數和擊殺數仍各自保存。戰役接續無盡時，計數沿用 R49 結算扣除戰役階段後的結果。
- 舊存檔會保留既有解鎖、金幣和最高紀錄。第一次實際打完無盡後才會出現新建議。換關時會回到說明開頭，長文可在詳情區內捲動。

## 本輪驗證

- 用獨立 GDScript 靜態分析器檢查三份遊戲程式與新增的回歸腳本，沒有回報錯誤。九種戰場規則均有招式名稱、計數與對策，八個直接載入的資源路徑均存在。遊戲字型包含本輪修改行使用的 34 個漢字。
- 比對 R49 程式，挑選漏接招式的排序規則相同。版本、Web 匯出快取、回歸腳本入口與 UID 已核對。三支原有的 Node 測試也通過，分別涵蓋載入失敗復原、WebGL 狀態快取及手機啟動流程。
- [R50 引擎回歸腳本](../scripts/debug/endless_practice_r50_test.gd) 涵蓋新舊存檔交替載入、分關保存、零施放、全數成功，以及 320×568、844×390、1280×720 的文字與按鈕可達性。腳本已列入 CI，本輪未執行引擎或啟動遊戲，因此實際換場、畫面與效能仍待實測。

這是本機開發提交。Apple 待審的 1.0.0 build 7 與線上版本未變更。
