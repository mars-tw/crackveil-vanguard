## 清單（逐項可驗收）

1. 結算加一行「輸出：隊長 X%・隊員合計 Y%（N 人）」，傷害列記錄隊長／隊員身分。驗收：R23 單元鎖定算式與顯示；審查圖 12、13、14、21 可見。
2. 包抄攻勢的答案標記只畫在靠近隊長的一側，中央由 4 個圖示＋4 個字標減為 2＋2。驗收：單元鎖定；審查圖 06。
3. 失敗建議只在倒下時陣形真的錯才寫「需 X，當時 Y」；陣形對時改寫「陣形對了（X），但先前錯陣反噬 N 次」。封隙狀態帶入全部可接受陣形。驗收：單元三案例。
4. 直式結算卡片區太擠時改為每頁一張卡，不以省略號收尾。驗收：單元；審查圖 13。
5. 機器人能辨識結算畫面並按「下一關」，審查集補入第二關翠晶花園與首領畫面。驗收：審查圖 18、20。
6. 固定閘門：原生 CI 全綠、Web 真輸入六模式、規則機器人兩局 0 錯誤、15 張實看審查集、release 驗證。
