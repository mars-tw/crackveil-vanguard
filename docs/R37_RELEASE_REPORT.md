# R37 開源更新

版本 `0.25.0-r37`。程式、可重建原始素材與測試一起更新；生成的 WebAssembly、遊戲包與本機長錄影不放入 Git。

## 本輪改動

- 手動拔刀在準備動作中可向 220–540 範圍內的外圈目標踏進，最多 180 單位。移動使用真正物理根節點，第 2 個攻擊姿勢才造成傷害；近怪、自動普攻、已開始的旋斬不會被推走。受傷、暫停、目標更換及死亡會清掉踏進狀態。
- 野地、環道、路肩有更清楚的材質層次；八處地標依造型調整大小並移到通路外。世界仍為 4096 × 3072 的週期地圖，角色可持續移動。
- 魔物危險圈與方向箭頭更清楚，護盾重擊預告仍對齊 145 半徑。提示重繪限制為 30 Hz。
- 傷害數字改為單個描邊文字節點，減少重複字體與排版通知；空場普攻搜尋、特效服務查詢及 HUD 靜態配置也減少重複工作。攻擊數量、真正傷害與逐幀角色動畫保留。
- 修正部署流程的舊版本檢查與停用地圖驗證，補齊 WebGL 腳本的 Git 追蹤。公開素材來源改用相對路徑，並增加可攜的資產／來源雜湊檢查。

原本六關世界地圖、各關 Boss 與無盡模式、六種特殊菁英、裝備掉落、金幣抽技能及永久寵物一起納入開源版本。

## 實際驗證

31 個 CI 遊戲回歸場景、31 項資產檢查與兩項 JavaScript 檢查通過。受控實驗以真正 Space 輸入、PlayerController、移動及動畫運行，角色踏進 180 單位後，在第 2 幀命中原本位於約 500 單位外的三隻敵人；預備階段沒有提前傷害。

真正 Chrome 鍵盤與觸控操作沒有注入血量、金幣、敵人或技能。相同 Intel ANGLE renderer、不錄影、相同種子與輸入策略的結果如下：

| 取樣 | 平均 FPS | 中位 FPS | 最低 FPS |
| --- | ---: | ---: | ---: |
| R36 桌機 30 秒基準 | 59.76 | 60 | 58 |
| R37 桌機 30 秒 | 59.97 | 60 | 59 |
| R37 手機尺寸 45 秒 | 59.72 | 60 | 57 |

兩個桌機候選都達到顯示更新上限，敵群與投射物峰值也因時序不同而改變，因此不把差值當成固定效能提升百分比。此次手動實玩有 10 次真正大斬命中，旋斬 8 次 impact／9 次命中，放開後狀態清除；近怪情境沒有觸發踏進，沒有把受控測試冒稱自然遊玩觀察。

乾淨提交副本另外完成匯入、Web 匯出與實際按鍵檢查，擊殺 14 隻，觸發約 180 單位的踏進及 2 次命中；沒有依賴未提交的本機素材。九份歷史原畫的 C2PA 來源驗證也通過。

## 範圍

手機、平板版面以 Chrome 觸控模擬及四種橫、直向尺寸驗證，沒有替代實體 iOS／Android 裝置測試。實際聽音與長時間六關通關不在本輪實測範圍。發布由 GitHub Pages workflow 完成，具體建置結果以 Actions 紀錄為準。

文案更新記錄：「本機版本、尚未公開」改為公開版本與 Pages 入口，避免讀者使用舊預覽；「六張固定插畫、限制站立區域」改為週期世界說明，符合現在可持續移動的實際行為。
