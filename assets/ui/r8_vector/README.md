# Crackveil Vanguard — R8 向量 UI 圖（原創 SVG）

本資料夾為原創向量 UI 素材，主題為「裂開的古石庭、金色封印、青色符文微光」。
全部為純 SVG 1.1，未使用文字、字型、Logo、點陣圖、外部連結、filter 或 CSS。
每個檔案開頭皆有原創宣告註解。座標皆為整數或一位小數，每檔小於 12 KB。

## Godot 使用提示

- 九宮格框：將 SVG 匯入後，在 `NinePatchRect` 或 `StyleBoxTexture` 設定上表邊距即可拉伸，中央透明區會透出底下內容。
- `badge_wrong_ring.svg` 為疊加層，請放在徽章節點之上，尺寸與徽章一致（128×128）。
- 三款陣形徽章底座規格一致，可直接互換顯示以表示目前陣形。
