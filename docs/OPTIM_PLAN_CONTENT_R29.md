# R29 優化計畫：第二關專屬招式「藤蔓纏地」、擊破字卡不被擋

版本 **0.58.0-content-r29**，基準 `411ad67`（R28）。

## 來源
- R28 Claude 8.6、Codex 8.8，皆嚴重 0。兩份第 1 項：第二關精英要有第一關沒有的可見招式。Codex 第 4 項：「擊破・藤爪獵將」被底部三選一蓋住。

## 清單
1. 翠晶花園精英每次出招，在目標腳下放藤蔓纏地圈：預警 1.1 秒（倒數弧），之後 2.4 秒內站在圈內的英雄被減速 45% 並持續小量受傷。精英登場提示寫「出招時腳下纏藤，散開站位」。驗收：單元；審查圖 18、20。
2. 大字事件字卡（擊破・名稱）遇到底部道具列時往上移，所有版面都把道具列列為避讓區。驗收：單元。
3. 固定閘門。
