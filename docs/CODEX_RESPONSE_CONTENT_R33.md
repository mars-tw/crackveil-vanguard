## 雷柱分流的四版迭代（照實記錄）
1. 隊長左右各 130、判定半徑 46、要求兩柱都有人：機器人 14 次 0 次；數值模擬發現連散兵站位都搆不到。
2. 柱子放在散兵第 1、5 站位、要求原地站穩：主局與直開局 0/17；截圖顯示柱子因「不壓封隙」被推到畫面外，換陣冷卻也來不及。
3. 改為封隙附近不施放、以隊長為中心：快速驗證 0/1、0/5（只有 4 人時無解、多數時間被封隙抑制）。
4. **現行**「隊長踩柱＋散兵接另一柱」：單元測試以實際陣形站位驗證——4 人散兵可解、4 人楔形／圓陣不可。第四關直開局快速驗證 **7 次分流 4 次**；正式管線的直開局 1/6、四關主局 0/7。
- 正式管線成功率低於快速驗證：機器人只會走向較近的柱、會被敵群推擠，第 20 張兩柱都轉綠但該局最終 0/7，表示爆發瞬間仍有人離柱。這是機器人操作能力的限制，不代表規則無解（單元測試與快速驗證都證明可解），但真人難度仍需試玩確認。
