## 技術限制
- 純 SVG 1.1：只用 path／rect／circle／polygon／polyline／line／g／linearGradient／radialGradient。**不可**嵌入點陣圖（不可 `<image>`、不可 base64）、不可 `<text>`、不可外部連結、不可 filter（Godot 的 SVG 匯入對 filter 支援差）、不可 CSS `<style>`（屬性直接寫在元素上）。
- 每個檔案 ≤ 12 KB，座標取整數或一位小數。
- 九宮格框的透明中央要真的透明（不要填色）。
- 每個檔案開頭加一行註解：`<!-- Crackveil Vanguard original vector asset, generated by MUSE (Meta muse-code) 2026-10-27 -->`
