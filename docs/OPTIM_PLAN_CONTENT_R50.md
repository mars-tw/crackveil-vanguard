# Crackveil Vanguard 內容優化 R50 計畫

玩家回到世界地圖選擇同一關時，可以看到上一場無盡遠征實際遇到哪一招、處理了幾次，以及下一場可以怎麼練。

- 使用 R49 結算已扣除戰役階段的施放與處理次數。優先顯示有出招且未完全處理的規則。全部處理成功時，顯示這場守住的招式。菁英尚未出招就結束時，照實顯示。
- 每關只保存最近一場無盡遠征的練習紀錄。歷史最高波數、擊殺數與舊版存檔維持原有含義。
- 沿用世界地圖的關卡資訊區。切換戰場時更新對應紀錄，並保留守關者、難度與關卡說明。
- 驗收涵蓋戰役接續無盡、換關、覆寫前一場、讀回存檔、舊存檔、全數處理成功及零施放。窄螢幕需同時看得到出擊與返回按鈕。
