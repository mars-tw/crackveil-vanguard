# 裂隙先鋒：產品區隔

2026-10-15，遊戲版本 `0.29.0-r44`。PREPARED：本機遊戲改動與送審材料；沒有修改商店、重送或更新正在審查的 build 3。

**一句話：帶領有獨立武器與生命的英雄小隊，在敵潮中切換楔形、圓陣、散兵，讓隊長與兩名隊友實際站好陣位，逐道封合裂隙。**

## 前三分鐘看得見的差異

R43 的三陣演練只要求移動並按過三種陣形。R44 新增「三陣封隙」：出擊即出現地面陣記，依序為楔形、圓陣、散兵。隊長要走進半徑 54 的陣記，至少兩名活著的隊友要距其真實陣位不超過 66，連續維持 1.2 秒。離開、選錯陣形或隊友沒到，進度歸零。封合後下一陣記換位置，戰鬥不中斷。每道回復全隊 8 HP；每關首次全封可得 4 殘響並永久記錄，存檔失敗不發錢。

玩家在敵潮中面對「繼續輸出，還是停下等隊伍整隊」的取捨。按鍵本身無法完成任務。楔形傷害 +15% 但受傷 +8%；圓陣受傷 -10% 但傷害 -8%；散兵拾取 +60%、移動 +8% 但傷害 -5%。羈絆與四名英雄被動另會消費陣形狀態。主選單第一按鈕直接寫「三陣封隙・出擊」，玩法頁與戰鬥常駐提示都教同一流程。

可重現證據：`scripts/services/formation_relay.gd`、`scripts/heroes/squad_manager.gd`、`docs/evidence/r44-store/mechanics.json`；實際無頭輸入紀錄及截圖在本輪 evidence 與 screenshots。這些是本機候選版，無法代表 build 3 已含新玩法。
