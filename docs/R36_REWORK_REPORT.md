# R36 環狀世界、特殊菁英與金幣用途

本機版本 `0.24.0-r36`，2026-10-02。預覽入口：<http://127.0.0.1:8072/?r36_preview=5>。

## 實際改動

每關改為 4096 × 3072 的週期世界。角色可持續朝任意方向走，環狀主路、中央十字支路與八處地標提供方向感。鏡頭跟著角色移動，周邊地景接續；怪物從當下畫面外產生，不把角色限制在舊的小矩形內。世界地圖仍可選六關，通關後解鎖該關無盡模式。

普通敵潮起手每 0.22 秒產五隻，30 秒後每批六隻；上限依裝置調整，走遠後回收普通怪，讓新區域繼續出怪。特殊菁英於 18 秒開始，每 28 秒輪替出現。它們有名稱、不同攻擊起手與能力，攻擊傷害跟著真正的命中格發生。

| 特殊菁英 | 能力與應對 |
| --- | --- |
| 焰爆術士 | 八向火焰彈；看地面預警，穿過彈幕空隙。 |
| 霜環守望者 | 十向霜晶彈與近身緩速；拉開距離，別停在力場內。 |
| 星盾重衛 | 護盾減傷與範圍重擊；蓄力時露出破綻，抓空檔輸出。 |
| 裂群召喚師 | 召喚五隻小魔物；優先擊倒敵群來源。 |
| 雷爪獵將 | 蓄勢後真衝鋒，搭配雷彈；沿側邊走位避開。 |
| 逐金魔靈 | 逃跑並沿路灑金幣，擊敗額外給 65 金幣。 |

菁英沿用稀有以上裝備保底；Boss 必掉傳說。金幣現在跨局保存，可從左下召喚按鈕或 `B` 開店：80 金幣抽當局技能、120 金幣抽永久寵物。費用、當下有效候選機率、保底及不足金額都在店內顯示。

裂線每輪由少量彈幕改為 12 發，可升到 16／20 發，起手間隔 0.34 秒；再搭配追蹤飛彈、回旋刃與 220–360 範圍的近身斬／旋斬。流星雨、星雷珠、霜晶槍與追影刃分別發出 8／8／12／10 顆實際攻擊物，傷害與碰撞均有效。持續旋斬有能量消耗，放開回復，不會只播放特效。

寵物包含範圍火球的焰尾靈狐、連鎖雷擊的星雷羽鷹，以及治療、經驗磁吸與靈光攻擊的翠玉靈兔。最多三隻出戰，重複抽到會升星，收藏在下一局自動載入。寵物走路、攻擊使用真正的不同姿勢。

手機預設自動選升級及自動旋斬，可在左側切換手動；搖桿控制移動，右下可點按拔刀或按住旋斬。平板有自己的介面與鏡頭倍率，保留手動選卡。桌機使用 WASD／方向鍵移動，空白鍵點按或持續施放。

## 驗證與體驗回報

最終預覽使用 `index-080af36b47b8.pck`；32 項 Godot 回歸檢查與載入復原、WebGL 狀態快取兩項 JavaScript 檢查通過。獨立體驗員透過真正 Chrome 按鍵、點選與觸控操作，桌機實玩 91 秒、手機尺寸 61 秒、平板尺寸 20 秒。未錄影活動取樣的 FPS 中位數為 57／59／60；桌機最低曾到 22，仍有尖峰掉幀。

長局在 R4 完成；R5 僅修正觸控版面，另做手機、平板各 15 秒的真正 Web 操作補驗與四尺寸控制區檢查。商店、搖桿、自動戰鬥按鈕正常，所有互動區均無重疊。最終約 12 秒的展示影片由兩段真正操作片段剪輯，保留原速，包含按住旋斬、移動、寵物與法術；原始錄影與剪輯區間均保留。

獨立覆核發現並修復三個菁英問題：契約與已購買的經驗獎勵未套用、衝鋒被擊退後無預警續衝、護盾重擊的預告範圍小於傷害範圍。新增檢查確認生成失敗保留獎勵、重新衝鋒必須再蓄勢，以及預告圈與 145 半徑的傷害圈一致。

- 環狀世界、六種菁英、護盾減傷、召喚、真衝鋒、金幣與裝備掉落均有實際遊戲節點驗證；敵人跨週期後立即更新查詢索引。
- 10 秒火力測試實際產生 403 顆攻擊物，其中裂線 348 顆；密集場景保留所有邏輯攻擊與傷害，視覺超額時才隱藏多餘繪製。
- 原生正常操作實玩跨越超過一個完整世界週期，沒有固定邊界或突然傳送；地標節點重複使用。
