# R30 優化計畫：荊藤纏地一眼看出是危險

版本 **0.59.0-content-r30**，基準 `ba27d7a`（R29）。

## 來源
- R29 Claude 8.6、Codex 8.9，皆嚴重 0。兩份第 1 項：藤蔓圈是綠色細圓環，與友方綠色混淆、預警與生效差異不足、無名稱、無減速提示。

## 清單
1. 藤蔓圈改血紅邊框與底色，畫帶刺藤蔓；預警期淡、生效期濃並轉動；名牌「荊藤纏地・散開」；圈內英雄頭上「緩」標記。驗收：單元；審查圖 18、20。
2. 子集字型缺「蔓」字 → 招式改名「荊藤纏地」；新增字型覆蓋檢查，新畫面字串缺字即失敗。驗收：單元（已驗證檢查能抓到缺字）。
3. 重疊藤蔓只畫一塊名牌；名牌先放圈下、被規則字條或精英名牌擋住改放圈上、都擋就不畫；同時最多 2 個藤蔓圈。驗收：單元；審查圖 18、20。
4. 結算「荊藤纏地 N 次・隊員被纏 M 下」，只計實際出現的圈。驗收：單元。
5. 固定閘門。
