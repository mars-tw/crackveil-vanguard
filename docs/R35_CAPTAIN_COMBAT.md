# R35 隊長連斬與旋斬

日期：2026-10-02，Asia/Taipei。

近身普攻改為橫斬、回斬、旋斬收尾三段，每段六個獨立身體姿勢。前兩段朝敵人出刀，第三段實際傷害覆蓋四周；連斬索引固定按順序推進，不消耗掉裝或刷怪的亂數。

短按 Space 或手機技能鍵保留原來的拔刀大斬：基礎 72 傷害、蓄滿 108、2.35 秒冷卻。按住超過 0.23 秒轉為持續旋斬，能量 120、每段消耗 12、間隔 0.36 秒；滿量可施放約 3.6 秒。耗盡後繼續按住不會回能或繼續旋斬，放開後每秒回復 22 能量。

傷害仍只發生在每段攻擊第 2 格。命中前放開會取消尚未承諾的傷害、退回該段能量並進入真正的收招姿勢。長按接手自動攻擊中的短按緩衝時，會消耗那個緩衝，避免旋斬結束後突然多打一記大斬。暫停、死亡、重開與離場會清掉旋斬等待和特效擁有者。

持續施放期間的小額受擊保留攻擊姿勢；實際扣血達最大 HP 的 12%，或呼叫者指定強打時，會把一段受傷姿勢排在當前攻擊完成之後。護盾吸收後沒有扣血的強打不會排入硬反應。待機與行走受擊仍直接播放受傷姿勢。

素材由內建 ImageGen 依既有隊長身份製作，原始圖與局部修正圖都保留在 `assets/art/r35/`。十八個新姿勢以單一固定比例機械切取，沒有用整張角色圖旋轉代替轉身。新 `r35_character_atlas.png` 為 2048 × 4032；原 R34 的 459 個播放格和上半張所有像素原封不動。新增區域採 160 px 格，舊區域維持 128 px 格；兩者的腳底相對圖片中心都偏下 54 px，沿用同一個物理根節點、角色尺度與共用材質。

`get_channel_debug_state()` 提供能量、持續輸入、旋斬命中、待命傷害、耗盡狀態與三段連斬計數。特效只在命中格呼叫 `combat_presentation.play_effect`；旋斬循環從第一次命中開始建立單一擁有者，並在釋放時呼叫 `set_channel(..., false, ...)`。暴擊仍交由敵人的統一傷害入口結算，隊長不重複擲暴擊。

`CaptainComboChannelR35Test` 已驗證十八個不同動畫區域、前兩段方向傷害、第三段背後命中、短按轉長按、命中前取消、暫停取消、滿能量十段施放、耗盡停止、放開回能、輕重受擊與死亡／重開清理。舊的動畫、拔刀斬和物件池測試也已通過。這些是工程驗證；實際特效素材就緒與遊玩觀感由整合和體驗員另外檢查。
