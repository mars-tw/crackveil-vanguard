# R32 裝備掉落與升級體驗

日期：2026-10-02。範圍：局內掉落、三槽裝備、升級卡與相關工程驗證。既有永久殘響升級、商店價格及存檔格式維持原契約。

## 已完成

擊殺敵人現在會掉落有實際屬性的裝備。武裝核心、護甲、戰靴各占一槽，四個品質等級依序為精良、稀有、史詩、傳說。物品在戰場上有品質色光柱、槽型圖示、品質點數與名稱；約 145 像素內開始磁吸，隊員也能拾取。拾取時顯示裝備名稱及全隊收益，HUD 三槽可直接查看完整屬性。

同槽較強裝備自動換上，較弱裝備拆解成金幣。每件物品只能領取一次。每個槽位的所有屬性均按同一強度曲線成長，換上強度更高的裝備不會降低其他屬性。世界上最多保留 10 件實體掉落，超出時回收最早的一件，避免戰場物件持續累積。

裝備套用的是新舊差額。例如原有護甲提供 24 HP，換成提供 36 HP 的護甲後，只再增加 12 HP。玩家已選過的生命、速度、拾取範圍升級保留；新招募隊員取得當前全隊裝備效果，每次同步不重複加值。新局清除裝備及其加成。

## 掉落與保底

| 來源 | 掉落規則 |
| --- | --- |
| 普通敵人 | 基礎機率 3.5%，每次未掉落增加 0.25 個百分點；第一件最晚第 12 殺，之後最長 28 殺沒有裝備 |
| 普通掉落品質 | 精良 66%、稀有 25%、史詩 7.5%、傳說 1.5%；連續三件精良後，下一件至少稀有 |
| 菁英 | 每隻必掉；稀有 60%、史詩 34%、傳說 6% |
| Boss | 必掉傳說；勝利彈窗之前領取 Boss 裝備及所有尚未拾取的裝備 |
| 開局三件 | 優先補空槽，同時預留尚未拾取物品的槽位，讓前三件填滿三種槽位 |

Boss 在世界即將暫停時直接領獎，勝利畫面不會把裝備留在地上。普通與菁英裝備保留可見的落地、散開及磁吸過程。

## 升級卡

- 顯示本局等級、強化次數及經驗進度。
- 數值升級讀取當前 runtime 資料，呈現傷害、冷卻、投射物、穿透或範圍的前後數值。
- 冷卻卡同時顯示換算後的攻速增幅。
- 顯示強化或質變階段，以及選完本卡後的武器進化增幅、質變與等級條件。
- 招募卡顯示隊伍人數變化、英雄肖像、角色定位與具名羈絆；角色引言保留在 tooltip。
- 卡片依實際繁中字型排版高度增高，完整內容可透過外層捲動閱讀。

## 接口與整合

`scripts/services/loot_director.gd` 由 Arena 建立為 `LootDirector`，加入 `loot_director` group。

```gdscript
setup(run_arena: Node2D, run_seed: int)
on_enemy_defeated(position: Vector2, is_elite: bool, is_boss: bool, type_id: String)
collect_all_loot()
apply_member_bonuses(member: Node)
get_outgoing_damage_multiplier() -> float
get_incoming_damage_multiplier() -> float
get_fire_rate_multiplier() -> float
get_stats() -> Dictionary
```

Enemy 在每次生命的死亡結算中呼叫掉落接口，且在 Boss 勝利結算前執行。GameManager 把裝備倍率納入實際傷害與攻速計算，減傷在所有來源合併後才套既有 soft cap，stats 與結算摘要包含裝備資料。招募流程在永久加成後同步裝備。

`equipment_changed(stats)` 與 `loot_collected(item, replaced, equipped)` 可供後續介面使用。裝備面板透過內容 signature 快取樣式，相同的 10 Hz stats 不重建 StyleBox；暫停或系統彈窗出現時隱藏，避免覆蓋彈窗。

掉落使用獨立 `RandomNumberGenerator`，種子為 run seed XOR 固定 salt。視覺散開角度由物品序號推導，延遲生成掉落物不會改變後續掉落序列，也不消耗遭遇生成使用的全域 RNG。

## 實機發現與修正

整合端在實際瀏覽器觀察到箭頭缺字及招募長文裁切。整合端補齊字型符號；本 lane 精簡招募預覽並加入依真實文字高度增高卡片的處理，再以三畫幅的真實招募文案驗證可見文字邊界。

繁中文案採 mode 2。主要修改如下：

| 原句 | 原因 | 改成什麼 |
| --- | --- | --- |
| 選擇升級 | 缺少當前成長進度 | `Lv.N · 選擇升級`，另顯示強化次數及經驗 |
| +4 傷害 | 不容易比較當前收益 | `基礎傷害 X → Y（+Z%）` |
| 冷卻 -12% | 玩家需要知道實際施放頻率 | `施放間隔 X → Y 秒` 與攻速增幅 |
| 招募引言＋長描述＋泛稱「專屬武器與羈絆」 | 重複文案擠掉角色定位與羈絆名稱 | 卡面保留人數變化、定位、具名羈絆；引言留在 tooltip |
