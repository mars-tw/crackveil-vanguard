# R41 優化計畫：花開提示依原因、被介面蓋住的封隙改用指標、遠射答案不再消失、事件字與花開後果更清楚

版本 **0.70.0-content-r41**，基準 `42431d6`（R40 評審補記）。

## 來源
- R40 Claude 8.5（嚴重 3）、Codex 8.6（嚴重 0）。
- Claude 嚴重 1：第 21 張花開後頂欄叫玩家「下次留能量旋斬」，畫面上能量卻是滿格，失敗原因其實是沒走過去。
- Claude 嚴重 2：第 19、20 張第 3 道封隙徽章大半壓在左下「陣形」「技能」面板底下，「第3道」字牌離徽章很遠。
- Claude 嚴重 3：第 08 張遠射攻勢中看不到「快封／慢封」答案標籤。
- Claude 第 4 件：花開長出的靈花要跟一般小怪分得出來，藤纏要畫出來。
- Claude 第 5 件、Codex 第 2 件：事件字要有層級；「擊破・名稱」金字被箭矢穿過。

## 清單
1. 花開提示依原因：記錄隊長是否曾走進花蕾圈、花開當下能量是否足夠（低於 16 或耗盡）。能量不足→「下次留能量旋斬」；沒走到→「下次先走到花蕾旁」；走到但沒按住→「下次在花蕾旁按住旋斬」。驗收：單元；第九關審查圖。
2. 被介面蓋住的封隙：封隙在畫面內、但中心落在陣形鈕、技能鈕、能量條、裝備列下方時，視同看不到，改畫邊緣指標（陣形徽記＋箭頭＋「第 N 道」），「第N道・到位」字牌從指標旁開始找位置。驗收：單元；機器人截圖。
3. 遠射答案位置：答案徽章依序試每個落點的上方、下方，取第一個不被頂欄等介面擋住、也不進裝備列的位置；不再因第一個落點靠近頂欄而整個不畫。驗收：單元；第 08 張審查圖。
4. 花開後果看得見：花開時每位被纏住的隊員腳下畫綠色藤圈（持續纏住的 1.6 秒）；長出的靈花腳下出現粉色五瓣花印 2 秒。驗收：單元；第九關審查圖。
5. 事件大字描邊：32 字級以上的事件字（擊破・名稱）描邊 3→9。驗收：單元；審查圖。
6. 固定閘門。
