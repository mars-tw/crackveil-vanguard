# R45 優化計畫：花蕾不藏在頂欄下並拉引線、判定字不壓自己的封隙、擊殺框全不透明、計時器加底板

版本 **0.74.0-content-r45**，基準 `b62eb1c`（R44 評審存檔）。

## 來源
- R44 Claude 8.0（嚴重 2）、Codex 8.3（嚴重 0）。
- Claude 嚴重 1：第 21 張判定字「圓陣正確・無人中招」壓在第 2 道封隙圖示上，「第2道」小字被蓋掉。
  - 原因：判定字被上方保留帶往下推到封隙上。R44 的橫移只避開 HUD，沒避開自己的封隙圓環。
- Claude 嚴重 2：第 19 張寫「4 秒內走過去旋斬」，畫面上卻找不到花蕾本體，也沒有指向。
  - 原因：花蕾生成時的畫面邊界寫死 200 像素，手機 3 倍像素時只剩 67 介面像素，花蕾會種在頂欄底下。
  - 地上字牌被推離花蕾後，也沒有線指回去。
- Claude 第 2、5 件：
  - 擊殺框右側菱形裝飾壓到數字最後一碼（08、17、20）。
  - 93% 底色仍透出指標與草地（05、17、20）。
  - 計時器沒有底板，被敵人與封隙圓環穿過（05、19、21）。

## 清單
1. 花蕾生成範圍改用介面像素再換算畫面像素。
   - 桌面維持左 220／右 240／上 200／下 200。
   - 矮的手機畫面改為上緣 40%、下緣 34% 高度內，花蕾落在頂欄與底部按鈕之間。
   - 驗收：單元；手機第九關審查圖看得到花蕾。
2. 花蕾字牌被推離花蕾超過圓環 40 像素時，從字牌最近的邊拉虛線到花蕾外環，顏色跟字牌框一致。
   - 驗收：單元；審查圖。
3. 判定字橫移時，把自己封隙的圓環也當成障礙（圓環先內縮 6 像素，緊貼封隙上下方的原位置不受影響）。
   - 驗收：單元；手機審查圖不再壓「第N道」。
4. 下列四處底色全部改為 100% 不透明：
   - 左上狀態框；
   - 擊殺金幣框；
   - 連斬框；
   - 頂欄。
   - 驗收：單元；審查圖。
5. 擊殺金幣數字右緣離框邊至少 18 介面像素，不碰角落菱形裝飾。
   - 驗收：單元實際建立 HUD 量測；審查圖。
6. 計時器加不透明底板（同狀態框配色），並登記為地上字不可放區域。
   - 驗收：單元；審查圖。
7. 舊測試同步（依「允許改規則並同步更新舊測試」）：R44 測試有四處比對原始碼字串，本輪改了寫法，同步為新字串，檢查意圖不變。
   - 擊殺框底色 0.93 → 1.0；
   - 連斬框底色 0.94 → 1.0；
   - 判定字障礙清單改為 `blockers`（含 HUD 與自己的圓環）；
   - HUD 面板清單多了 `TimeLabel`。
8. 潮紋標記讓開答案徽章（第一次管線發現）：第八關手機 00:44 潮紋標記（紅色浪頭方向＋「2」秒倒數）壓住「楔快 6秒 補8」的「楔」字。
   - 潮紋標記沿浪頭方向左右滑開，避開已登記的答案徽章與字牌，再把自己登記進去。
   - 第三次管線補修：浪頭貼近畫面右緣時每個位置都被擋或被拉回畫面內，標記退回原位壓在「楔快」上；改為每個候選位置先拉回畫面內再比較，全部有遮擋時取遮擋面積最小的位置。
   - 驗收：單元；手機審查圖。
9. 首領名牌不被「第N道」字牌蓋住（第一次管線發現）：第八關手機 03:26「第2道」字牌壓住首領名牌「深潮歌后」上半。
   - 原因：名牌在物理幀先放，「第N道」字牌在之後的畫面幀才放，字牌移動的那一幀名牌還在原位。
   - 維持 R12 規則「字牌不動，名牌讓開」：字牌放好後，被它蓋到的首領／菁英名牌當幀重新找位置。
   - 驗收：單元；審查圖。
10. 花蕾倒數點讓開答案徽章（第二次管線發現）：第九關手機 03:09 花蕾右上的「4」秒倒數點壓到「散慢」徽章圖示。
    - 倒數點依序試圓環右上、左上、右下、左下，取第一個不碰已登記字牌、徽章與 HUD 的角落，再登記自己。
    - 驗收：單元；審查圖。
11. 「第N道」字牌不再退回原位壓住答案徽章（第二次管線發現）：第八關手機 00:43「第1道」字牌蓋住「楔快／圓慢」兩個徽章圖示下半。
    - 原因：隊員擠在一起時，每個候選位置都碰到隊員，字牌找不到位置就退回預設位置。
    - 第一輪找不到時，第二輪允許蓋在隊員上，但仍避開字牌、徽章與 HUD。
    - 驗收：單元；審查圖。
12. 分叉碎彈的射手已消失時不再報錯（第三次管線發現）：機器人局記錄到 4 次「spawn_fork_projectile 無法轉換第 4 個參數」。
    - 原因：碎彈用延後呼叫生成，射手在呼叫執行前已被移除，已釋放的物件無法傳進限定型別的參數。
    - 改為不限型別接收，射手已不存在時碎彈照常生成、不記來源。
    - 驗收：單元（傳入已釋放的射手）；管線 0 錯誤。
13. 固定閘門。
