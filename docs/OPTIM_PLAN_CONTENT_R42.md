# R42 優化計畫：HP 框有真正的血條、貼邊封隙改用指標、第八九關手機橫式取證

版本 **0.71.0-content-r42**，基準 `a679f4f`（R41 評審存檔）。

## 來源
- R41 Claude 8.6（嚴重 2）、Codex 8.5（嚴重 0）。
- Claude 嚴重 1：HP 框內的青色長條與血量對不上（HP 190／190 只填兩成），玩家會以為快死了。實際上那是經驗條，「EXP」字樣在最大字級時放不下，R10 起就隱藏，HP 本身沒有任何條。
- Claude 嚴重 2：第 08 張「第 3 道」字牌擠在左緣，旁邊看不到陣形徽章和箭頭。實際原因：封隙只露出畫面左緣一點點，仍被算成「在畫面內」，所以沒有畫邊緣指標。
- Claude 第 4 件、Codex 第 2 件：第八、九關缺手機橫式截圖。

## 清單
1. HP 血條：HP 字後面加一條紅色血條（從愛心到 Lv 標籤、在經驗條上方），隨 HP 比例變化；HP 字加深色描邊確保壓在紅條上仍清楚；暫停時跟著 HP 字隱藏；每個 HUD 排版（桌面、手機橫式、手機直式、精簡橫式）都由 HP 字、愛心、Lv、經驗條的實際位置推出，不另寫座標。驗收：單元；所有戰鬥審查圖。
2. 貼邊封隙：封隙中心離畫面邊緣不到 110 個螢幕像素（隨縮放換算）就算看不到，改畫邊緣指標（陣形徽章＋箭頭＋「第 N 道」），字牌接在指標旁。驗收：單元；第 08 張審查圖。
3. 手機橫式取證：機器人新增手機模式（844×390、3 倍像素、觸控裝置），第八、九關直開局各跑一局，審查圖換入手機橫式的潮紋與花蕾畫面。驗收：審查圖原圖 2532×1170。
4. 字牌就近：「第 N 道」字牌原位被答案徽章、首領名牌等占住時，改先試封隙上下、左右的近位置，所有候選由近到遠排序（原本第二個候選就是全畫面格點的最左上角；R40 同一張圖已是這樣）；另外字牌只在當下真的需要邊緣指標時才跟著指標排，不沿用上一幀的指標位置。驗收：單元；第 08 張審查圖。
5. 固定閘門。

- 第十關以後專屬機制、戰鬥中央資訊減量、陣形對錯的非文字回饋。
