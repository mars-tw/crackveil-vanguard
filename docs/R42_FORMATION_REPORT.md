# R42 陣形戰術報告（0.27.0-r42）

計畫：[OPTIM_PLAN_R42.md](OPTIM_PLAN_R42.md)。執行者：Claude（Codex 額度用完，使用者授權改由 Claude 執行本輪）。

## 做了什麼

- **陣形戰術**（`scripts/heroes/squad_manager.gd`）：三種陣形的站位與數值、4 秒冷卻、換陣地面光環與連線、提示文字。
  - 楔形突擊：隊友前壓到兩翼，全隊傷害 +15%，受到傷害 +8%。
  - 圓陣護衛：內圈 6 人、外圈 2 人圍住隊長，受到傷害 -10%（仍受全域軟上限 0.85 約束），全隊傷害 -8%。
  - 散兵游擊：隊友以 236 px 半徑散開，拾取範圍 +60%、移動 +8%，全隊傷害 -5%。
- **羈絆 × 陣形共鳴**：燼脈聯爆↔楔形（傷害 +8%）、縫獵協議↔散兵（傷害 +8%）、星盾和聲↔圓陣（每秒回復 1.5 HP）、牧長裂約↔圓陣（傷害 +8%）。
- **四名英雄被動**（原本標示「預留」，沒有實際作用）：斥候（隊友移動 +10%）、補線（拾取 +20%）、守衛（換陣冷卻 -40%，每次換陣全隊護盾 14 點 2.5 秒）、爆破（楔形時傷害再 +10%）。起始隊伍包含守衛與斥候，所以開局就有陣形加成。
- **操作**：桌機 `Q` 或左下「陣形」按鈕（召喚按鈕上方）；手機在「斬」上方 64×44 按鈕，冷卻時顯示秒數。開局 6 秒若還沒換陣，提示一次。暫停 →「本局」顯示目前陣形、效果與共鳴。
- **戰鬥配樂**：本機 ACE-Step 生成的原創器樂，24 秒無縫循環，進入戰鬥時淡入、結束時淡出。來源見 `docs/evidence/r42/audio/provenance.json`。
- 版號 0.27.0-r42；原生商店版號 1.0.0（iOS build 3、Android versionCode 3）。`tools/export_mobile.py` 改讀 `native/build-config.json` 的 build 號。
