## 八大面向

| 面向 | 本輪做／不做及理由 |
|---|---|
| 美術 | 做既有配色下的目標／陣形 UI；沿用已存在素材。本輪無新圖，無模型生成，不以方塊冒充素材 |
| 按鈕 | 做手機陣形直選與取消，命中至少 44px；390×844、844×390 及既有矩陣驗證 |
| 選單 | 做陣形可取消直選、暫停目標與主選單收藏；保留可見返回與繼續 |
| 人物 | 不新增角色；沿用既有臉部、剪影與辨識度 |
| 地圖模型 | 不新增地形；用十關既有主題對應菁英與世界觀紀錄深化關卡 |
| 技能 | 做換陣冷卻／效果／拒絕回饋；菁英與護衛沿用既有可預告技能 |
| 角色樣子 | 不改 atlas／色盤；既有亮度／飽和度與素材閘仍須執行 |
| 動作流暢度 | 不改動畫管線；走位／攻擊／hurt／death 皆沿用真逐幀，保留命中幀規則與既有回歸 |

## 品質閘門與限制

- 跑 CI 權威 37 場景、R31EndgameGate、R42FormationTest 與新增 R43；CI 三支 Node 測試、既有控制可達性 8 視口全綠。
- 本機 Web 匯出僅作 headless Chromium 測試；保存 before／after 至 `docs/evidence/r43-mobile/`，至少兩手機視口及 1366×600。
- 版本更新、舊版號只在歷史紀錄、秘密掃描零命中；本輪僅明確路徑 git add，本地繁中 commit。
- 效能數字一律標「並發載量測，僅供參考」；不宣稱通過出貨效能閘。
- 獨立覆核：已載入 orchestrator 規範，DevSpace `chatgpt_list_workers` 回傳 Internal error；不改用瀏覽器或其他模型冒充。保留該外部覆核缺口，確定性驗證照常完成。
- 新美術／音樂不在本輪；若需要新資產，列缺件，不生成占位成品。實機 iOS／Android 驗證不在本機無頭範圍。
