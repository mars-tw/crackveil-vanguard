# R31 優化計畫：第三關「熔火環爆」、藤蔓不壓封隙、緩標記置頂

版本 **0.60.0-content-r31**，基準 `e57705e`（R30）。

## 來源
- R30 Claude 8.6、Codex 8.9，皆嚴重 0。Claude 第 1 項與 Codex 第 4 項：第三關以後也要有專屬規則。Claude 第 2 項：藤蔓壓在封隙上時「散開」與「到位」衝突。兩份：「緩」被角色與特效蓋住。

## 清單
1. 緋星熔庭精英出招時以目標為中心放熔火環：環帶（64～170）預警 1.4 秒後爆炸 14 傷害，中心與環外安全；中心向內箭頭與「熔火環爆・往中心集合」名牌；同時最多 1 個；名牌避開規則字條與精英名牌。與第二關「散開」相反。驗收：單元；審查圖 19、20、21。
2. 藤蔓圈不落在開啟中的封隙上（推離 150＋半徑）。驗收：單元；審查圖 18。
3. 「緩」改帶刺紅環，畫在獨立最上層，多人重疊時錯開。驗收：單元。
4. 結算新增「熔火環爆 N 次・隊員被燒 M 人次」。驗收：單元；審查圖 21。
5. 規則機器人可連過兩次「下一關」，審查集拍到第三關。
6. 固定閘門。
